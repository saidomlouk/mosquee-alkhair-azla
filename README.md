# لوحة مشروع بناء مسجد الخير أزلا V6

التعديلات:
- حذف عارض 360 نهائياً.
- وضع الصورة الجديدة كصورة عادية كبيرة تظهر كاملة داخل الموقع.
- إضافة فيديو الجمع العام وفيديو زيارة البقعة من Facebook كـ iframe.
- إضافة إمكانية إدخال مساهم جديد من داخل الموقع.
- الإحصائيات تتحدث مباشرة بعد الإضافة.
- الإضافات تحفظ في نفس المتصفح LocalStorage.

ملاحظة مهمة:
فيديوهات فيسبوك غالباً تحتاج الموقع يكون منشور على الإنترنت باش يخدم التضمين بشكل أفضل.
على GitHub Pages ستظهر إن شاء الله مباشرة.
